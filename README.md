## Overview

This project was completed for the Spring 2026 course *EEL6812: Intro to Neural Networks and Deep Learning*. The project aims to predict post-implementation circuit delay metrics from a pre-synthesis (RTL code) representation.

## Directory Structure

- `ast-parser/`: Yosys AST to feature extraction scripts used to turn RTL into PyTorch tensors and graph features.
- `models/`: Main QoRNet training and evaluation code for linear regression, MLP, and GNN models.
- `eda-pipeline/`: Scripts and data for the EDA pipeline used to produce ground truth metrics.
- `resources/`: Reference papers and project materials used for methodology comparison.
- `data/`: Ground truth CSVs, graph tensors, and training configuration files.

## External Submodules

- `hdl-benchmarks/`: Collection of open-source RTL benchmarks used for training data.
- `Open-EDA-Flow/`: Containerized Yosys/OpenROAD flow support, developed by Cory for a past course project.

## Dependencies

### Python

Install the Python packages listed in `requirements.txt`:

```bash
python3 -m pip install -r requirements.txt
```

### EDA Tooling

The framework also relies on external EDA tools that are not installed through `requirements.txt`.

- `Yosys`
- `ABC` via the Yosys synthesis flow
- `OpenROAD`
- `Apptainer`

These tools can be accessed through an Apptainer image in the `Open-EDA-Flow` submodule. See usage instructions under `Open-EDA-Flow/README.md`. **Note**: the Apptainer `.sif` file can be quite large after it is built, nearly 20GB in size.

## Usage

1. Collect the ground truth data and ASTs for model training. Exact instructions are included under `eda-pipeline`.

2. Convert Yosys ASTs generated by EDA pipeline into vector- and graph-based PyTorch feature tensors. Usage instructions included in `ast-parser`.

3. Train models. Detailed instructions are included in each model directory under `models`. For an example training flow, run

```
python3 model/qornet.py --target_name "wns" \
--config synthesis/iscas_89_config.yaml \
--labels data/qornet_results_nonzero_tns.csv \
--dataset_dir data/iscas_graphs_new/tensors/ \
--plot_dir qornet_gnn_results_wns \
--checkpoint_path qornet_gnn_results_wns/qornet_checkpoint.pt \
--cv_folds 5 \
--cv_stratify_by_size \
--disable_verbose \
```

This will output diagnostic information and training results to a folder called `qornet_gnn_results_wns`. From there, five pre-trained model weights will be saved for each of the cross-validation folds. Evaluation can now be carried out on a per-design basis.

```
python3 model/qornet.py --mode inference \
--checkpoint_path qornet_gnn_results_wns/qornet_checkpoint_fold_1.pt \
--single_graph ast-parser/ast_parser_results/tensors/s349.pt
```
This command evaluates the `s349` design from the ISCAS '89 benchmark using the pre-trained model from CV fold 1. It will print out the predicted WNS along with the time taken to evaluate the model.
